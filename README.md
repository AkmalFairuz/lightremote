# LightRemote

[![Desktop build](https://github.com/AkmalFairuz/lightremote/actions/workflows/desktop-build.yml/badge.svg)](https://github.com/AkmalFairuz/lightremote/actions/workflows/desktop-build.yml)

LightRemote is a browser and desktop workspace for SSH terminals, VNC desktops,
and remote file management over SFTP, FTP, and explicit FTPS, powered by Go and
React. See the [documentation](docs/index.md).
